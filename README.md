# Smart Greenhouse IoT + AI Dashboard

An intelligent Smart Greenhouse monitoring and predictive analytics system integrating MQTT, Streamlit, SQLite, Plotly, and Machine Learning for real-time environmental monitoring, actuator control analytics, and next-hour climate prediction.

---

## Features

- Real-time IoT sensor monitoring
- MQTT publish-subscribe communication
- Live Streamlit dashboard
- SQLite database logging
- Interactive Plotly trend visualization
- Intelligent actuator status monitoring
- Fan/Fogger ON event counting
- Alert generation for critical conditions
- Machine Learning based prediction
- Next-hour Relative Humidity prediction
- Industrial-style responsive UI

---

## Parameters Monitored

- Temperature (°C)
- Relative Humidity (%)
- EC (dS/m)
- pH
- Fan-Pad Status
- Fogger Status
